Première version dans le Grenier : gestionnaire de mots de passe et de cartes cadeaux 100 % local, sans compte ni cloud.

### Nouveautés
- **Passe-Partout sur Android** : retrouvez vos comptes et vos cartes cadeaux sur votre téléphone.
- **Synchronisation par QR code** : pour retrouver les mêmes données sur le téléphone et l'ordinateur, il suffit de scanner le code affiché sur l'ordinateur. Tout reste entre vos deux appareils, rien ne passe par Internet.
- **Installation de l'appli sur le téléphone depuis l'ordinateur** : un simple QR code à scanner, sans passer par une boutique d'applications.
- **Mises à jour de l'appli** : quand une nouvelle version est disponible, le téléphone la reçoit de l'ordinateur pendant la synchronisation.
- Le numéro de version est maintenant affiché dans l'application.
