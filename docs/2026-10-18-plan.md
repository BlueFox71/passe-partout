# Passe-Partout — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Logiciel Windows local de gestion de mots de passe (profils, cartes cadeaux, verrou chiffré optionnel, import Excel, export texte/PNG) au style néon.

**Architecture:** Fenêtre pywebview (WebView2) affichant une UI HTML/CSS/JS vanilla dans `ui/`. Toute la logique est en Python dans le paquet `app/`, exposée au JS par une classe `Api` (pywebview `js_api`). L'UI parle à une interface unique `api.*` ; en dehors de pywebview, `ui/mock-api.js` fournit les mêmes méthodes sur données fictives (sert au prototype de la tâche 1, puis aux tests visuels).

**Tech Stack:** Python 3.13, pywebview ≥5, cryptography, openpyxl, Pillow, pytest, PyInstaller.

**Spec:** `D:\Documents\App Web\gestionnaire-mdp\docs\2026-10-18-conception.md`

## Global Constraints

- Nom du logiciel : **Passe-Partout** (titre de fenêtre, exe, raccourci, écran « Qui est-ce ? »). Icône : clé/serrure stylisée en dégradé `#ff3d9a` → `#7c3aed` lumineux ; 2–3 variantes à montrer à Jules pendant la Tâche 1.
- Interface entièrement en français.
- 100 % hors ligne : aucune requête réseau, aucun CDN, aucune police distante ; tout est embarqué dans `ui/`.
- Jamais de mot de passe dans un `print`, un log, un message d'erreur, un fichier temporaire ou une sortie de test sur les vraies données.
- Données dans `%APPDATA%\PassePartout\vault.json` (+ `backups\`), chemin injectable pour les tests.
- Palette : fond radial `#3b0f5c` → `#0b0716`, accent dégradé `#ff3d9a` → `#7c3aed`, secondaire `#00e5ff`, panneaux verre dépoli, police Segoe UI. Référence : maquette « Néon / gaming » de `.superpowers/brainstorm/1257-1792325999/content/style-v2.html`.

- Écriture atomique + 5 sauvegardes tournantes (chiffrées si verrou).
- Presse-papiers vidé 30 s après copie d'un mot de passe/code/PIN ; auto-verrouillage par défaut 10 min.
